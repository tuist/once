# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

### Breaking Changes

- Script actions now live under `[[target]]` with `kind = "script"` and
  `[target.script]`. Existing `[[task]]` entries must be migrated to the new
  form before upgrading.
- Inline script targets now use the same public contract names as annotated
  script files: `input`, `output`, `env`, and `cwd`.

### Added

- Native [Bazel](https://bazel.build) workspace integration. Once detects a
  Bazel workspace from `MODULE.bazel`, runs `bazel query` to enumerate every
  rule, and exposes each one as a `bazel_target` in the graph. Build, test,
  and run capabilities delegate execution to Bazel today; rule kinds Once
  learns to compile directly (for example rules_rs `rust_*` into Once's
  native `rust_*` kinds) will lower into those native kinds in later
  releases. A new `once bazel` compatibility surface accepts single-label
  `bazel build` and `bazel test` invocations, routes them through the Once
  graph, and forwards every other invocation to the system `bazel` unchanged.
  See the [Bazel guide](https://buildonce.dev/docs/guide/graph/bazel) and
  the [`bazel_workspace`](https://buildonce.dev/docs/reference/prelude/bazel_workspace)
  reference.
