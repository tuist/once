---
title: Documentation now lives in the Once app
date: 2026-07-26
---

The documentation moved from a separate static site into the Once web application,
served under `/docs`. It is rendered natively with the Noora design system, so the
docs and the marketing site now share one look and feel.

This unlocks upcoming interactive features like a package registry and live content,
and lets the docs run on the same infrastructure as the rest of Once.
