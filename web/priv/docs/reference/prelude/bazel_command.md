# `bazel_command`

Opaque Bazel workspace command.

## Description

This target runs the complete native Bazel workspace without translating its
individual labels into Once targets. It is normally generated by
[`bazel_workspace`](/reference/prelude/bazel_workspace), not written by hand.

## Providers

The target emits `bazel_workspace_command` and `once_test_info`.

## Capabilities

| Capability | Output groups |
| --- | --- |
| `build` | none |
| `test` | `test_results`, `test_logs` |

The build capability invokes `bazel build //...`. The test capability invokes
`bazel test //...`, preserves Bazel's exit status, and writes the native log
plus a normalized Once test result. Both operations are intentionally
uncacheable at the Once layer because Bazel owns its native incremental cache.

## Tools

| Tool | Executables |
| --- | --- |
| `bazel` | `bazelisk`, `bazel` |
| `shell` | `sh` |

Use Bazel directly when you need a narrower label, configuration flags, a
query, or another subcommand.
