# Action presentation

Small ecosystem-neutral data contract shared by analysis and reporting. Keep stable package/platform/context IDs separate from display labels. Normalization bounds optional metadata and drops invalid IDs without truncating their meaning. No execution inputs, execution/cache identity, host probes, ecosystem dispatch or UI styling belongs here. Every field must deserialize with a legacy default. Allow at most eight platforms and eight context entries and 2048 bytes of string data in total. Namespace tokens are at most 64 bytes, package names and labels at most 128 bytes, stable identifiers/values at most 256 bytes. Oversized display labels are omitted, never silently shortened. Core events box this optional record to avoid growing every event on the bus. Update the event protocol and server-side normalization when this shape changes.

`ActionHistoryKey` is a separate producer-owned logical-history contract, never presentation or execution/cache identity. Its namespace is an ASCII token (1–64 bytes), its opaque key is valid UTF-8 (1–128 bytes) without controls. Missing/invalid keys are omitted. Keep this crate independent of core/analysis/reporting and preserve legacy serde defaults. The frontend hashes bounded canonical components; the server independently derives a project-scoped identity and suppresses ambiguous within-run matches.
