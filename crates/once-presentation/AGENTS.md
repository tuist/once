# Action presentation

Small ecosystem-neutral data contract shared by analysis and reporting. Keep stable package/platform/context IDs separate from display labels. Normalization bounds optional metadata and drops invalid IDs without truncating their meaning. No execution inputs, action identity, host probes, ecosystem dispatch or UI styling belongs here. Every field must deserialize with a legacy default. Allow at most eight platforms and eight context entries and 2048 bytes of string data in total. Namespace tokens are at most 64 bytes, package names and labels at most 128 bytes, stable identifiers/values at most 256 bytes. Oversized display labels are omitted, never silently shortened. Core events box this optional record to avoid growing every event on the bus. Update the event protocol and server-side normalization when this shape changes.
